# CommentsApp — frontend

React 19 + TypeScript + Vite, архитектура Feature-Sliced Design.
Описание проекта, запуск и архитектура — в [README в корне репозитория](../README.md).

```bash
npm install
npm run dev     # http://localhost:5173 (API: https://localhost:7066, см. .env.development)
npm run build   # проверка типов + production-сборка в dist/
npm run lint
```
